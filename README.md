# POS (Punto de Venta) Modo Offline - Backend

Backend del sistema POS desarrollado con Node.js y Express, siguiendo el patrón MVC.

## Descripción del proyecto

Este backend gestiona la lógica del sistema:

- autenticación de usuarios
- gestión de productos
- registro de ventas
- control de caja
- manejo de tickets
- conexión con base de datos PostgreSQL

## Tecnologías usadas

- Node.js
- Express.js
- PostgreSQL
- dotenv
- cors
- bcrypt
- jsonwebtoken

## Estructura del proyecto

```bash
src/
 ├── config/
 ├── controllers/
 ├── middlewares/
 ├── models/
 ├── routes/
 ├── services/
 ├── utils/
 └── index.js
```
